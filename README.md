

# ci-cd-final-project

## Project Description

This project demonstrates a Continuous Integration and Continuous Deployment (CI/CD) workflow using GitHub Actions and Tekton.

## Technologies Used

- GitHub Actions
- Python
- flake8 for code linting
- nose for unit testing
- Tekton for pipeline tasks
- OpenShift for application deployment

## Project Objectives

- Automate code linting and testing.
- Run unit tests during the CI workflow.
- Execute cleanup and testing tasks using Tekton.
- Build and deploy the application through an OpenShift pipeline.
